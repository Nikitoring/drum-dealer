# UI-компоненты

В проекте есть небольшой набор переиспользуемых компонентов в `apps/frontend/src/components/ui`. Компоненты не привязаны к бизнес-сущностям и используются в публичных и административных формах.

| Компонент | Назначение |
| --- | --- |
| `DrmButton` | Основные, вторичные и опасные действия |
| `DrmInput` | Однострочные текстовые, телефонные и email-поля |
| `DrmTextarea` | Многострочный текст и комментарии |
| `DrmSelect` | Выбор категории, статуса, состояния и других значений |
| `DrmCheckbox` | Флаги и согласие на обработку персональных данных |
| `DrmTable` | Табличное отображение товаров, заявок и расписания |

Компоненты экспортируются из `components/ui/index.ts`. Стили каждого компонента лежат рядом с его исходником в отдельном CSS-файле. Бизнес-компоненты каталогов, бронирования и админки используют этот слой для базовых контролов.
